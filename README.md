# 🎯 Jogo do Número Secreto

Jogo simples e interativo onde o jogador tenta adivinhar um número aleatório entre 1 e 100. Desenvolvido com HTML, CSS e JavaScript.

## 🧠 Funcionalidades

- Geração aleatória de número secreto  
- Validação de palpites  
- Contador de tentativas  
- Reinício do jogo  

## ♿ Acessibilidade

- Feedback falado com voz **feminina brasileira** usando `responsiveVoice.js`

## 💻 Tecnologias

- HTML5  
- CSS3  
- JavaScript  
- Biblioteca [responsiveVoice.js](https://responsivevoice.org/)

## 🚀 Como Executar

1. Baixe ou clone o repositório  
2. Abra o arquivo `index.html` em um navegador moderno  
3. Digite um número e jogue!
